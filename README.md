# MDForge

Coquille du projet MDForge : future forge de compilation documentaire.

## Etat actuel

- `Mddocx/` — sous-projet MDDOCX (submodule, `Crackovis/Mddocx`), conserve tel quel.
- `launch_mdforge.bat` — lanceur trivial qui delegue au lanceur de MDDOCX.

## Usage

```bat
launch_mdforge.bat
```

Le refactoring de la forge (logique unifiee au-dela de MDDOCX) reste a formaliser.
