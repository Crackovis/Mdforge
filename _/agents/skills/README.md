# Skills locaux — MDForge

Ce dossier est réservé aux procédures réutilisables propres à MDForge lorsqu'elles deviennent assez stables pour être exécutées par plusieurs agents.

Ne pas recopier les skills génériques du host TAKOUDJOU (`memory-router`, PACTE, publication documentaire, etc.). Les futurs skills locaux pourront couvrir par exemple l'auteur de plugin MDForge, la vérification d'un module de sortie ou l'audit d'un projet documentaire — seulement après que leurs contrats auront été stabilisés par l'architecture et l'implémentation.
