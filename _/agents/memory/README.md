# Mémoire permanente locale — MDForge

Ce dossier est réservé aux nœuds de mémoire **durables et MDForge-spécifiques** qui ne relèvent pas du plan d'évolution `roaming/` : décisions stabilisées, architecture devenue canonique, état durable ou index locaux devenus nécessaires.

À la fondation, il reste volontairement minimal. On n'invente pas un registre complexe avant que le besoin existe.

Règle : une vision ou architecture encore en exploration vit dans `_/agents/roaming/memory-diagrams/`. Une décision n'entre ici qu'après stabilisation et avec provenance vers le Target/commit qui l'a établie.
