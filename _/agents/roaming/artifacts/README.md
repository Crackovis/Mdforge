# Artifacts — MDForge

Zone des preuves d'exécution agentique et baselines liées aux Targets MDForge : audits, snapshots de contrat, résultats de tests, matrices de compatibilité, preuves de migration et autres matériaux vérifiables.

Un artifact prouve uniquement ce qu'il contient. Il ne remplace jamais le code au SHA, un test reproductible ou un Memory Diagram.

Les artefacts générés lourds et temporaires restent hors Git sauf décision explicite de conservation.
